### ❓ ЧТО ТАКОЕ АГРЕГАТНЫЕ ФУНКЦИИ?

До этого момента мы работали со строками таблицы по отдельности. Однако в реальных задачах бэкенду часто нужно получать сводную (агрегированную) информацию: узнать общее количество записей, посчитать сумму, найти среднее, минимальное или максимальное значение в столбце.

Для этого в SQL существуют **агрегатные функции**:
* **`COUNT(*)`** или **`COUNT(column)`** — подсчитывает количество строк.
* **`SUM(column)`** — вычисляет сумму значений числового столбца.
* **`AVG(column)`** — находит среднее арифметическое значение.
* **`MIN(column)`** — находит минимальное значение.
* **`MAX(column)`** — находит максимальное значение.

---

### 🗄️ ГРУППИРОВКА ДАННЫХ: GROUP BY

Если применить агрегатную функцию к таблице напрямую (например, `SELECT MAX(length_minutes) FROM table2`), СУБД вернет ровно одну строку со значением для всей таблицы. 

Но что, если нам нужно посчитать статистику **для каждого режиссера отдельно**? Для этого существует оператор **`GROUP BY`**. Он разделяет данные на группы (кучки) по значению определенного столбца, а затем применяет агрегатную функцию к каждой группе независимо.

**Синтаксис группировки:**
```sql
SELECT column_name, COUNT(another_column) 
FROM table_name 
WHERE condition 
GROUP BY column_name;
```

### ⏳ ФИЛЬТРАЦИЯ ГРУПП: В ЧЕМ РАЗНИЦА МЕЖДУ WHERE И HAVING?

> **⚠️ Критический нюанс (Капкан на собеседованиях и экзаменах):**
> Оператор **`WHERE`** фильтрует *индивидуальные строки* **ДО** того, как СУБД начнет объединять их в группы. Он ничего не знает про агрегатные функции (запрос вроде `WHERE COUNT(id) > 2` вызовет синтаксическую ошибку).
> 
> Чтобы фильтровать уже *сгруппированные результаты* (например, отсечь режиссеров, у которых суммарно меньше 3 фильмов), используется оператор **`HAVING`**. Он выполняется строго **ПОСЛЕ** группировки.

**Полная архитектура сложного запроса:**
```sql
SELECT column_name, AGGREGATE_FUNCTION(col)
FROM table_name
WHERE строка_соответствует_условию
GROUP BY column_name
HAVING результат_агрегации_соответствует_условию;
```

#### 📋 Задачи для самопроверки:
1. Посчитать общее количество фильмов в таблице.
2. Найти самый длинный и самый короткий фильм по продолжительности среди всей базы.
3. Посчитать количество фильмов, снятых *каждым* режиссером (вывести имя режиссера и количество его работ).
4. Вывести только тех режиссеров, которые суммарно сняли *больше 2 фильмов*, и указать количество их картин.

#### ✅ РЕШЕНИЯ:

1️⃣ Простой подсчет строк во всей таблице:
```sql
SELECT COUNT(*) FROM table2;
```

2️⃣ Использование функций экстремумов `MAX` и `MIN`:
```sql
SELECT MAX(length_minutes), MIN(length_minutes) FROM table2;
```

3️⃣ Группировка по режиссеру с подсчетом строк в каждой группе:
```sql
SELECT director, COUNT(*) FROM table2 GROUP BY director;
```

4️⃣ Группировка с последующей пост-фильтрацией через `HAVING`:
```sql
SELECT director, COUNT(*) FROM table2 GROUP BY director HAVING COUNT(*) > 2;
```
