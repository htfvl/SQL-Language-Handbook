### ❓ ЗАЧЕМ ФИЛЬТРОВАТЬ ДАННЫЕ И РЕЗУЛЬТАТЫ?

Хотя данные в самой базе данных могут быть уникальными, результаты конкретного запроса часто содержат дубликаты. Например, если мы запросим только год выпуска из таблицы фильмов, мы получим много одинаковых значений, так как в один год могло выйти несколько картин. 

В таких случаях SQL предоставляет инструмент для отбрасывания строк с дублирующимися значениями с помощью ключевого слова **`DISTINCT`**.

**Синтаксис уникальной выборки:**
```sql
SELECT DISTINCT column_name, another_column FROM table_name WHERE condition(s);
```

### 🔀 СОРТИРОВКА: ORDER BY

В отличие от аккуратно упорядоченных учебных таблиц, в реальные БД данные добавляются хаотично и хранятся без определенного порядка. По мере роста таблицы до тысяч или миллионов строк, читать результаты становится невозможно.

Для решения этой проблемы SQL позволяет сортировать результаты по заданному столбцу по возрастанию (**`ASC`** - Ascending) или по убыванию (**`DESC`** - Descending) с помощью оператора **`ORDER BY`**.

**Синтаксис сортировки:**
```sql
SELECT column_name FROM table_name ORDER BY column_name ASC/DESC;
```
> **💡 Примечание:** При использовании `ORDER BY` строки сортируются в алфавитном или числовом порядке на основе значений указанного столбца. В некоторых БД также можно настраивать правила сортировки (collation) для корректной работы с международными алфавитами.

### 📄 ПАГИНАЦИЯ (СМЕЩЕНИЕ И ЛИМИТЫ): LIMIT & OFFSET

Часто `ORDER BY` используется в связке с операторами **`LIMIT`** и **`OFFSET`**. Это мощнейшая оптимизация для извлечения строго определенного подмножества данных.
* **`LIMIT`** — ограничивает максимальное количество возвращаемых строк.
* **`OFFSET`** — (необязательный параметр) указывает, сколько строк нужно пропустить с начала перед тем, как начать вывод.

**Синтаксис пагинации:**
```sql
SELECT column_name FROM table_name ORDER BY column_name ASC LIMIT num_limit OFFSET num_offset;
```

> **🌐 Пример из жизни:** Такие сайты, как Reddit или Pinterest, используют этот механизм для главных страниц. Первая страница — это список постов, отсортированных по популярности (`ORDER BY`) с лимитом, например, в 20 записей (`LIMIT 20`). При прокрутке вниз загружается следующая страница с тем же лимитом, но уже со смещением в 20 записей (`OFFSET 20`). Это позволяет БД работать максимально эффективно, не загружая всю миллионную базу в оперативную память.

#### 📋 Задачи для самопроверки:
1. Вывести список всех режиссеров (в алфавитном порядке) без повторений.
2. Вывести названия последних (самых новых) четырех фильмов в порядке от самого нового к самому старому.
3. Вывести первые пять фильмов в алфавитном порядке.
4. Вывести следующие пять фильмов (с 6 по 10) в алфавитном порядке (имитация второй страницы).

#### ✅ РЕШЕНИЯ:

1️⃣ Уникальная выборка режиссеров с сортировкой (А-Я):
```sql
SELECT DISTINCT director FROM table2 ORDER BY director ASC;
```

2️⃣ Топ-4 самых свежих фильмов (сортировка по году по убыванию + лимит):
```sql
SELECT title FROM table2 ORDER BY year DESC LIMIT 4;
```

3️⃣ Первые 5 фильмов по алфавиту:
```sql
SELECT title FROM table2 ORDER BY title ASC LIMIT 5;
```

4️⃣ Вторая "страница" фильмов по алфавиту (смещение на 5 записей):
```sql
SELECT title FROM table2 ORDER BY title ASC LIMIT 5 OFFSET 5;
```
