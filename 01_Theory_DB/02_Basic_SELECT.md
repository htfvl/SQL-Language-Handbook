## 🟢 02) SQL_BASICS: SELECT QUERIES / ОСНОВЫ ВЫБОРКИ ДАННЫХ

### ❓ ДЛЯ ЧЕГО ИСПОЛЬЗУЮТ ЗАПРОС SELECT?
Оператор **`SELECT`** — это главный инструмент в SQL, который используется для извлечения (выборки) определенных данных из одной или нескольких таблиц базы данных.

### 📑 СТРУКТУРА БАЗОВОГО SELECT ЗАПРОСА:
```sql
SELECT название_колонки_1, название_колонки_2 FROM название_таблицы;
```

Используя нашу таблицу транспортных средств **`table1`**, разберем основные типы выборок.

3. Найти все модели и типы каждой машины.
4. Найти все модели и количество дверей каждой машины.

---

### ✅ SOLUTIONS / РЕШЕНИЯ ЗАДАЧ:

1️⃣ Извлечение только столбца моделей:
```sql
SELECT Model FROM table1;
```

2️⃣ Извлечение только столбца типов кузова:
```sql
SELECT Type FROM table1;
```

3️⃣ Выборка нескольких столбцов через запятую (Модель и Тип):
```sql
SELECT Model, Type FROM table1;
```

4️⃣ Выборка Модели и количества дверей:
```sql
SELECT Model, Doors FROM table1;
```

5️⃣ Извлечение абсолютно всех столбцов и строк из таблицы с помощью оператора `*` (**ALL**):
```sql
SELECT * FROM table1;
```
