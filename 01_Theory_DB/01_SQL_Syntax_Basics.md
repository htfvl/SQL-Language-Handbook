## ❓ ЧТО ТАКОЕ БАЗА ДАННЫХ И СУБД?

Для правильного понимания природы уязвимостей SQLi необходимо четко разделять два базовых понятия:
1. **База данных (БД)** — это организованная структура, представляющая собой коллекцию взаимосвязанных двумерных таблиц.
2. **СУБД (Система Управления Базами Данных)** — это специализированное программное обеспечение (например, *PostgreSQL, MySQL, Oracle, SQLite*), которое обрабатывает запросы к БД, позволяя создавать, изменять, удалять и извлекать информацию.



Каждая таблица внутри реляционной БД концептуально похожа на таблицу Excel с фиксированным количеством именованных **столбцов** (атрибутов) и произвольным количеством **строк** (записей с данными).

### 🔗 РЕЛЯЦИОННЫЕ СВЯЗИ (RELATIONS)

Сила реляционных БД заключается в возможности связывать таблицы между собой с помощью уникальных идентификаторов (`ID`). 

В рамках архитектуры одного приложения рядом с таблицей машин (`vehicles`) могут находиться другие связанные таблицы:
* 👤 `drivers` — Список всех зарегистрированных водителей (Имя, Фамилия, Паспортные данные).
* 🪪 `licenses` — Категории и типы водительских удостоверений, привязанные к конкретным ID водителей.
* 🧾 `fines` — История штрафов, где каждая запись ссылается на ID водителя и ID машины, на которой было совершено нарушение.

СУБД позволяет объединять эти таблицы «на лету» с помощью SQL-запросов, собирая полную картину данных для бэкенда.
