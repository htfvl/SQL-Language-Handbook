SQL Language Handbook

Полноценная база знаний по SQL: от базового синтаксиса до продвинутых запросов.

О проекте:

Этот репозиторий — структурированная база знаний по SQL и реляционным базам данных.
Проект создан на основе личных заметок из Obsidian и переработан в формат полноценной технической документации.

Главная цель репозитория:

объяснить SQL простым языком;
показать логику работы запросов;
научить писать SQL самостоятельно;
помочь новичкам разобраться в базах данных;
собрать удобный reference handbook.
